# .github

Organization-wide files for [Bank of an Agent](https://github.com/bank-of-an-agent):

- [`profile/README.md`](profile/README.md): the organization profile page.
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md),
  [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SUPPORT.md`](SUPPORT.md): default community health
  files for every repository.
- [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) and [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md).
- [`brand/`](brand): logo, banner and diagram sources, palette and the render script.

GitHub shows the profile and applies the default community files only while this repository is
public. A member-only copy of the profile lives in `.github-private`.
